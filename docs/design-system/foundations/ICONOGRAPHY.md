# Iconografia
Status: EXISTING + PROPOSED

## Base observada
Lucide React fornece SVGs. AppShell usa ícones Dashboard, Scale, Swords, MessagesSquare, Settings, Search, Bell, Menu, X e LogOut. Evitar emojis como ícones.

## Regras
Manter mesmo traço e alinhamento; ícone decorativo é oculto de leitor de tela; controle só com ícone tem nome acessível. Estado deve incluir texto/forma, não cor isolada. Alvos de toque devem ser confortáveis (meta de produto 44px; WCAG mínimo é diferente).

## Glass
Ícone e foco ficam acima da placa estabilizada e continuam nítidos. Highlight não invade a forma. Usar cor semântica existente e não adicionar icon library.
